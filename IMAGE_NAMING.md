# VVS FLAWLESS — convention des images produit

Format retenu :

`NNN-model-slug/NN-view.ext`

Exemple :

`005-new-model/01-front.webp`
`005-new-model/02-angle-right.webp`
`005-new-model/03-side.webp`
`005-new-model/04-back.webp`
`005-new-model/05-bracelet.webp`

Règles :
- 1 dossier = 1 montre.
- Le numéro du dossier ne change jamais.
- Les images d'une montre commencent à 01.
- Utiliser des noms de vues descriptifs : front, angle-left, angle-right, side, back, bracelet, clasp, hand, detail.
- Le prochain identifiant disponible est indiqué dans `resources/data/watch-image-catalog.json`.
- Les noms publics restent génériques et sans marque tierce.
